# /docs — Синхронизация PROJECT_KNOWLEDGE.md с фактом

Файл в `.cursor/commands/docs.md` — текст, который подставляется в чат при выборе `/docs`.

## Цель

Привести `@PROJECT_KNOWLEDGE.md` (и при необходимости `CURSOR.md`, `README.md`) к фактическому состоянию репозитория **структурно**, без append-only-лога. Используется после серии изменений, после рефакторинга или раз в неделю как профилактика дрейфа.

## Входы

- (Опционально) Узкая область: «только архитектура», «только точки входа», «только AI Layer Health».
- (Опционально) Период: «изменения за последние N коммитов / дней».

## Шаги для агента (обязательный порядок)

1. **Составить План** в `@PLAN.md` или `.cursor/plans/docs-xxx.md`: какие разделы синхронизируем, какие файлы трогаем.
2. **Собрать факты**:
   - `git log --oneline -N` и `git diff --stat <от>..<до>` — какие модули реально изменились.
   - Структура `.cursor/`, `scripts/`, корня — что появилось/исчезло.
   - `CHANGELOG.md` — какие принципиальные изменения зафиксированы.
3. **Проверить расхождения**:
   - Карта репо в `CURSOR.md` ↔ фактическая структура.
   - Разделы «Архитектура», «Текущий стек», «Точки входа», «Известные проблемы» в `PROJECT_KNOWLEDGE.md` ↔ факт.
   - Версия / дата в шапке `CURSOR.md` ↔ актуальная запись в `CHANGELOG.md`.
4. **Внести минимальные структурные правки**:
   - Менять разделы, а не «дописывать в конец».
   - Не вставлять формулировки «я добавил…», «починил…», «обновил…» (антипаттерн P3).
   - Если что-то стало неактуальным — убирать, а не зачёркивать.
5. **Запустить валидатор**: `node scripts/validate-layer.mjs`. Битые ссылки и append-only-лог должны быть пустыми.

## Ограничения

- Не править стиль/смысл `.cursor/PRINCIPLES.md` без отдельной согласованной задачи.
- Не трогать `.cursor/rules/*.mdc`, если расхождение не структурное (это работа для `/refactor` или `/reflect`).
- Лимит дифа: 200–300 строк правок документации — иначе разбить на несколько прогонов.

## Готово

- Валидатор зелёный.
- `@PROJECT_KNOWLEDGE.md` отражает фактическое состояние **структурно**.
- Дата в шапке `CURSOR.md` обновлена при значимых изменениях.
- План закрыт.
