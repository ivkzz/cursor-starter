# /bootstrap — Запуск ai-builder.md (настройка/обновление AI-слоя)

Файл в `.cursor/commands/bootstrap.md` — текст, который подставляется в чат при выборе `/bootstrap`.

## Цель

Выполнить полный сценарий `@ai-layer-builder/ai-builder.md` (Шаги 0 → 8) для целевого проекта: проанализировать репозиторий, дополнить/обновить правила, команды, хуки и оркестратор. Никакой полной перезаписи без явной просьбы.

## Входы

- Режим: `greenfield` (почти пусто) или `brownfield` (уже есть код).
- (Опционально) Особые пожелания: «не трогать существующий `.cursor/rules/`», «добавить только хуки», «полная переинициализация».
- (Опционально) Указание стека, если он не определяется тривиально.

## Шаги для агента (обязательный порядок)

1. **Составить План** в `@PLAN.md` или `.cursor/plans/bootstrap-xxx.md`:
   - Какие шаги `ai-builder.md` будут выполнены.
   - Какие файлы будут добавлены/изменены.
   - Что **не трогать**.
2. **Прочитать**: `@ai-layer-builder/ai-builder.md`, `@.cursor/PRINCIPLES.md`, `@.cursor/rules/anti-patterns.mdc`.
3. **Выполнить шаги ai-builder.md в порядке 0 → 8**, после каждого шага — короткий отчёт.
4. **Скилы (шаг 2.5)**: ничего не сканировать на диске пользователя без явной просьбы. Если пользователь хочет реестр глобальных скилов — он указывает их сам или через отдельный запрос.
5. **Хуки (шаг 4)**: генерируются только если в проекте есть `PLAN.md` / `PROJECT_KNOWLEDGE.md` / CI; формат — соответствующий Cursor IDE.
6. **Запустить валидатор**: `node scripts/validate-layer.mjs`. Если ошибки — починить до завершения.
7. **Обновить `CHANGELOG.md`** (раздел `[Unreleased]`): что добавлено/изменено/удалено, и почему это нужно именно этому проекту.
8. **Структурно обновить `@PROJECT_KNOWLEDGE.md`** (Архитектура, Точки входа, AI Layer Health/версия).

## Ограничения

- Полная перезапись `.cursor/`, `CURSOR.md`, `hooks.json` — **только** по явной просьбе пользователя.
- Не выдумывать скилы и команды; не создавать дубли существующих.
- Соблюдать `@.cursor/PRINCIPLES.md` P6, P7, P8.

## Готово

- Валидатор зелёный.
- `CHANGELOG.md` обновлён.
- `PROJECT_KNOWLEDGE.md` отражает новое состояние **структурно** (не логом).
- План закрыт.
