# План текущей задачи

**Используй этот файл для одной активной задачи.** После завершения — очисти или перенеси в `.cursor/plans/`.

---

## Как заполнять план (обязательно)

1. **Цель** — одна-две фразы, что именно делаем.
2. **Контекст** — точечные `@` файлы и артефакты (не весь репозиторий).
3. **Шаги** — нумерованный список, каждый шаг — атомарное действие.
4. **Риски** — что может пойти не так, как минимизируем.
5. **Готово, когда** — конкретные критерии завершения (тесты зелёные, док обновлён, PR готов и т.д.).

**Принцип**: план — это не эссе, а чеклист для агента. Коротко, но достаточно, чтобы агент мог работать автономно.

---

## Пример: Улучшение AI-слоя cursor-starter

**Цель**: Сделать AI-слой более честным и готовым к использованию — устранить заглушки в реестре скилов и усилить `PLAN.md`.

**Контекст**:
- `@CURSOR.md`
- `@PROJECT_KNOWLEDGE.md`
- `@.cursor/rules/project-skills-registry.mdc`
- `@.cursor/rules/core.mdc`
- `@ai-layer-builder/ai-builder.md`

**Шаги**:
1. Переработать `project-skills-registry.mdc` — явно зафиксировать отсутствие глобальных скилов.
2. Усилить `PLAN.md` — добавить реальный пример структуры.
3. Обновить `PROJECT_KNOWLEDGE.md` структурно (не логом).
4. Проверить, что ссылки в `CURSOR.md` и `ai-builder.md` не сломаны.

**Риски**:
- Переусердствовать и раздуть слой (нарушить token economy).
- Создать слишком много файлов без ценности.
- Сломать существующие ссылки между артефактами.

**Готово, когда**:
- Реестр скилов явно описывает текущее состояние (нет глобальных скилов).
- `PLAN.md` содержит понятный пример структуры.
- `PROJECT_KNOWLEDGE.md` обновлён структурно.
- Нет битых ссылок в `CURSOR.md`.

**Текущий статус**: Шаг 8 (Финализация) завершён.

**AI-слой cursor-starter — живая самообучающаяся система.**

- Нет готовых примеров — всё генерируется с нуля под проект
- Hooks создаются на основе анализа (PLAN.md, PROJECT_KNOWLEDGE.md, CI, стек)
- Есть механизм рефлексии (`/reflect`) — AI-слой анализирует свои ошибки и улучшает себя
- Не деградирует — рефлексия, адаптация, совершенствование

**Готово.**

**Что сделано:**
- Реестр скилов: глобальные скилы не обнаружены → агент использует только проектные команды
- PLAN.md: усилен реальным примером и шаблоном
- Hooks: 4 активных хука (plan-guard, knowledge-sync, rule-validator, plan-reminder)
- README: переработан с целевой аудиторией и примерами «до/после»
- CHANGELOG: создан
- Планы генерируются под проект (без готовых примеров)

**Готово, когда:**
- [x] Реестр скилов явно описывает текущее состояние
- [x] PLAN.md содержит понятный пример структуры
- [x] Hooks реально внедрены и описаны
- [x] README переработан
- [x] CHANGELOG создан
- [x] PROJECT_KNOWLEDGE.md обновлён структурно

**План можно закрыть.** Перенесён в `.cursor/plans/improve-ai-layer-plan.md` (опционально).
